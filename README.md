# Sorry! — The Game

**Sorry!** is a board game for 2–4 players in which each player races four pawns from Start, around the board, and into Home. Unlike its ancestors Pachisi, Ludo and Parcheesi, Sorry! uses a deck of cards instead of dice, and its name comes from the satisfying moment you knock an opponent's pawn back to Start ("Sorry!").

- **Players:** 2–4 (or 4 as two teams)
- **Ages:** 6 and up
- **Playing time:** about 30–60 minutes
- **Publisher:** Originally Waddingtons (UK) and Parker Brothers (US); now Hasbro
